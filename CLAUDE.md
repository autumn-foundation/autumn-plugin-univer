# CLAUDE.md

Autumn (autumn-web 0.8) plugin that serves Univer 1.0 spreadsheets.

## Layout

- `src/assets.rs` — `UNIVER_ASSETS` (`PluginAssets`), version pin, manifest tests.
- `src/bundle_files.rs` — generated by `vendor/build.mjs`. Do not edit.
- `src/plugin.rs` — `UniverPlugin`.
- `src/script.rs` — `univer_script()`, `univer_stylesheet()`.
- `src/spreadsheet.rs` — `Spreadsheet` builder, `save_button`, JSON escape.
- `src/workbook.rs` — `Workbook` model, builder, invariants, `Limits`.
- `src/extract.rs` — `WorkbookSnapshot` extractor (422 on invalid).
- `src/locale.rs` — `Locale` (variants gated by `locale-*` features).
- `assets/init.js`, `assets/autumn-univer.css` — plugin-authored browser files.
- `assets/dist/`, `assets/manifest.json` — generated vendor output. Do not edit.
- `vendor/` — npm pins and the esbuild script.
- `tests/system.rs` — Chromium tests (`--features system-tests`).
- `examples/univer_demo.rs` — demo app.
- `docs/plan.md`, `docs/adr/` — plan, AC, decisions.
- `docs/roadmap.md` — phases for docs, slides, extras and file exchange.

## Commands

```sh
cargo fmt && cargo clippy --all-targets --all-features -- -D warnings
cargo test
cargo test --features system-tests --test system
cargo llvm-cov --lib --features all-locales,hyphenation
(cd vendor && npm ci --ignore-scripts && npm run build)   # after npm pin changes
```

## Rules

- TDD: write the failing test first. Browser behavior needs a system test.
- No inline `<script>` code and no `style=` attributes in markup (CSP).
- After any `init.js` change, run the system tests.
- Docs and comments: short ASD-STE100 sentences.
- No `unwrap`/`expect`/`panic` outside tests (clippy denies them).
